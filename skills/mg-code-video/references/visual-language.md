# 参考片的画面规则与实现配方

以下时间码来自已下载的平台转码流。观察基于抽帧，精确切点与缓动需要连续回放确认。这里提炼视觉关系，不复述歌曲歌词，也不要求复用角色、商标或原片素材。

## 1. 把界面作为故事空间

观察：约 00:12–00:32，侧栏、对话区域、输入框和设置卡片构成主要空间；约 00:52–01:04，开关、滑块、日期和记忆设置参与表达内容；约 02:12–02:32，错误卡片、离线状态和弹窗占据界面；约 03:20–03:32 回到聊天窗口与输入状态。

复用规则：让状态变化推动故事，而不只把聊天窗口用作装饰。先为主角或主题建立一个可识别的空间，再使按钮、滑块、消息、加载状态或错误状态承担叙事动作，结尾回到早先空间形成呼应。

实现建议：将 UI 拆为可绘制组件，保存锚点、布局、文字、强调色和状态；同一组件跨镜头复用。用 `idle → typing → sent → waiting → error` 一类显式状态描述过程，避免只在时间线上任意添加弹窗。

## 2. 统一深底、暖色与状态色

观察：多数样本是深灰棕背景、细线框和浅色正文；橙珊瑚色贯穿花形符号、曲线及角色；约 02:16–02:32，错误状态引入高饱和洋红；高潮段暖色与浅色面积显著增加。

实现建议：从四类语义 token 开始：背景 `#211f1d`、正文 `#eee8df`、主强调 `#ef8b65`、错误 `#ed4488`。这些是近似建议值，并非精确取色。通过亮度、饱和度与强调色面积区分平静、亲近、失控和回落；不必为每个镜头另换一套配色。

## 3. 把抽象内容转换成图形动作

观察：约 00:36 是发光散点；38 秒附近出现连接点的线框体；约 00:39–00:41 是圆、半径和沿圆弧排布的文字；约 00:42.5–00:44，圆移到左侧，右侧出现正弦曲线；约 00:48 为带参考线的变化曲线；约 03:12 出现心形轮廓与坐标网格。

复用规则：每个抽象概念选择一个可解释的数学或图形隐喻，让观众看见“概念如何变化”。保持线宽、发光强度与标记点的统一，使不同图形属于同一个系统。

实现建议：圆与波可共享相位 `theta`：圆上点为 `(cx+r*cos(theta), cy+r*sin(theta))`，曲线为 `y=baseY+A*sin(k*x-phi)`。通过连线、投影或共享标记点解释两者关系。原片可见圆与波的接续，但没有源码证据证明其采用这些公式。

圆弧文字可按字符宽度累计弧长定位并沿切线旋转；先测量字宽，避免字符挤在固定角度间隔内。需要形变时，先将路径重采样为同数量、相同方向的点，再插值，防止扭结。

## 4. 让文字兼具解释与构图作用

观察：界面文字较小、克制；歌词或主题文字采用更显著的衬线层级；章节或强调词使用大号粗体及等宽风格；约 01:36–01:44 可见大字母作为左右构图区分；约 02:36–02:44，强调词不断占据更大画面面积。

复用规则：区分界面信息、叙事文字与冲击文字。小文字维持世界可信度，大文字承担主要视觉事件。用字号、描边与填充、重复和遮挡建立层次，不把所有句子都放在底部字幕条。

实现建议：字体就绪后测量排版；为长文本定义换行或缩放策略。沿路径排字、打字与重复文字可作为不同组件，不能默认所有文案都使用逐字出现。为冲击字保留足够停留时间，尤其在中文内容中重新验证可读性。

## 5. 用同一角色资产形成多种存在状态

观察：约 01:12–01:16 为橙色角色剪影；约 01:36–01:48 为橙、白、黑色块组合与多重轮廓；约 02:04–02:08 角色呈灰色点阵或字符纹理；约 02:48–03:04 使用近景裁切、横向碎片与嵌套窗口中的角色。

复用规则：保持轮廓与标志性符号一致，通过材质、尺度、遮罩和复制改变状态。单张人物图可以承担多段叙事，不需要每镜头更换一张生成图。

实现建议：以透明角色资产建立 alpha mask，派生纯色填充、描边、点阵与条带版本；使用不同相位的少量副本产生残影。横向切片可用分段裁剪加偏移实现；点阵使用预计算采样并缓存。以上为实现选项，不能据此声称原片使用特定 shader。

## 6. 通过密度与尺度组织情绪

观察：约 02:26–02:32 的密集采样显示，界面全景切到输入框近景，再回到带更多错误卡片的全景；中央弹窗的尺寸和存在感增加。约 02:48–03:00 的稀疏样本显示角色近景、碎片及重复嵌套窗口；约 03:24–03:32 再次减少画面元素。

复用规则：高潮同时调度信息密度、对象尺度、对比度和空间稳定性；结尾让元素减少，并复现开场建立的符号。不要全片持续堆满高频效果，否则失去升级空间。

实现建议：以情绪参数 `intensity` 驱动副本数、弹窗密度、抖动幅度和发光，但为每个属性单独设上限。主文字与角色轮廓维持识别度。需要递归窗口时，预先生成内层快照或使用分离的离屏画布，避免当前画布无限自绘。

## 用于新作品

先将用户内容映射为“叙事空间—图形隐喻—状态冲突—回归符号”，选择其中相关方法，不强制复刻原片段落或镜头数。

例如，用同一条曲线连接“输入—变化—结果”；用一个设置面板中的参数改变驱动后续图形；让同一枚图形符号在开场、高潮和结尾拥有不同尺寸与状态。分镜表应写清每个变化要传达的意义，再选动画技法。
