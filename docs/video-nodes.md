# 视频节点交互

## 导入与放置

- 右侧元素条点击「视频」先打开文件选择器，选中视频后再点击画布放置。取消选择或按 Esc 取消放置不会创建空节点。
- 支持将视频文件拖入画布，落在拖放位置；画布获得焦点后，Ctrl+V 可粘贴剪贴板提供的视频文件，放在当前视口中心。剪贴板必须实际提供文件，仅复制文件路径文字或网页链接不等于复制视频文件。
- 支持 MP4 / WebM / MOV / MKV，单文件上限 48MB（与现有播放器一致），能否解码取决于浏览器的编码支持。上传前读取尺寸、时长和首帧封面，上传使用 1MB 分块。
- 画布须先保存到工作区。文件完整上传后才创建带封面的原视频节点，保持原始宽高比并进入当前图层，可正常撤销。读取/上传失败不创建节点，切换画布或页面时取消导入并清理临时媒体。

验证：`node tools/check-video-import.mjs`，已纳入 `npm test`。

## 视频复刻：自主设置画质、帧率和范围

先保存画布并导入普通视频。选中视频，悬停或点击悬浮工具条的「绘制复刻」展开设置浮窗。设置复刻范围、帧率、采样画质、碎片数量、画风、颜色数及是否去背景，然后点击「让大肥鱼开始画画！」。视频在后台静默复刻，画布角落显示可收起的进度卡片，可继续操作画布、取消任务或在失败后按原参数重试。

- 范围可选完整视频或指定起止秒数，结束时间留空表示到视频结尾。到达源视频末尾时自动截短，输出时长以帧数 / 帧率计，误差不超过一帧。
- 帧率由用户输入任意正数，支持 25、29.97、30、60 fps 等。浏览器不可靠提供源帧率，因此不提供未经验证的「原帧率」选项；高于源帧率可能产生重复画面。
- 采样画质可选长边 480/887/1440px、原始尺寸或自定义长边，小视频不放大。视频复刻不再沿用图片内部 887px 长边封顶；碎片档位仍按采样密度区分画风。
- 移除 30 秒、360 帧和 640px 的固定任务限制，开始前显示预计帧数及采样尺寸。分辨率、帧率和时长越高，计算量、存储占用和导出体积通常越大。单帧处理仍须在 1600 万像素、16384px 长边以内，超出会明确报错。
- 浏览器抽取画面后与宿主复刻流水线重叠进行，在途帧数与常驻 Worker 池大小对齐（最多 4）。只有相邻帧上传的 PNG 内容及绘制参数完全一致时复用 SVG；已移除按灰度差判断的近似整帧复用。不同画面重新绘制轮廓，调色板复用前检查工作图的全部前景颜色，缺少亮色、颜色失配时重新聚类，并按调色板实际生成帧定期刷新。进度卡片显示已完成帧数和最近完成的 SVG 帧。需保持应用运行且浏览器支持源视频编码。
- 原视频保留。只有全部成功并检查帧数后，才在原视频右侧、同图层新建 SVG 视频节点；新增节点使用正常保存和一次撤销。
- 切换画布标签、页面或对话，以及临时隐藏画布时，绘制任务继续运行。任务和进度按会话、画布路径及页面隔离；重新打开原画布后恢复进度卡片。界面未挂载时完成的结果会保留，返回原页面并读取文档后自动加入，走正常保存和一次撤销，不会插入当前的其他画布。
- 主动取消、关闭该画布标签或检测到原视频被更改/删除时停止任务。取消与失败清理本次临时媒体，不保存半成品节点。失败可重新复刻，从头开始。任务缓存保留在当前浏览器应用内存中；刷新页面、退出应用或卸载插件会终止任务，不支持跨重启续绘。
- 网络中断可能导致临时包未清理，可用「清理未引用媒体」处理；已完成且被引用的结果不会自动删除。
- 完成后关闭面板，可在预览窗口播放、逐帧检查，并通过悬浮工具条「导出 → 导出 SVG 视频」导出 `.svgvideo.zip`（播放清单、SVG 帧、封面）。不含音轨，不是单文件动态 SVG。
- 碎片数量支持低/中/高，内部自动匹配每帧 60,000/120,000/248,000 字符预算，单帧文件格式上限 250,000 字符。复用图片的碎片画风，必要时自动简化；完成信息会提示发生细节降低的帧数。不做跨帧颜色或轮廓稳定。
- 高清 PNG 使用 1MB 分块传输；每帧在独立线程计算，仅计算用户选中的碎片档位。取消时终止当前计算线程，清理本次任务。

验证：`node tools/check-video-trace.mjs`，已纳入 `npm test`。

## 播放与导出

- 单击节点选中；点击节点中央播放按钮时也会选中该节点。
- 鼠标悬停视频节点时，中央显示播放或暂停按钮，底部显示进度条（类似常见视频站点）；移出后一并收起。加载中或出错时中央按钮仍常显以便重试。
- 选中原视频后显示「绘制复刻 / 预览 / 抽帧 / 导出」悬浮条，复用其他节点的图标在上、文字在下的布局、尺寸、主题色与悬停底色。SVG 视频显示「预览 / 抽帧 / 导出」，不显示不适用的绘制复刻。
- 绘制和导出复用图片绘制的悬停卡片组件，优先在工具条上方展开，空间不足时调整到视口内。移出后延迟关闭，移入浮窗取消关闭；输入参数时保持打开。点击外部或按 Escape 关闭。切换画布/页面会取消正在进行的视频复刻。
- 「抽帧」把当前画面放到原视频右侧（同尺寸、同图层，可撤销）。未播放时会先加载并停在当前进度。源视频导出当前解码画面的 PNG；SVG 视频直接使用当前帧的 SVG，不再栅格化，避免色块之间出现白缝。选区悬浮条不展示播放、停止、逐帧、进度、循环及适配控件，也不再提供设置封面。节点表面悬停条只负责进度与播放/暂停；完整控制（停止、逐帧、循环、适配、静音）在「预览」窗口操作。
- 图片和视频默认无外框，不提供不适用的描边工具，也不显示文字标签。
- 暂停保留当前位置，再次播放继续；停止回到开头。播放结束后再次播放从头开始。
- SVG 帧序列支持上一帧、下一帧；普通视频禁用逐帧按钮。
- 默认等比适配，可切换裁切填满或拉伸。此设置只影响本次预览。
- 双击节点或点击“放大”打开预览，按 Escape 或点击关闭返回画布，保持播放位置。
- 「导出」菜单按媒体类型筛选：原视频提供导出源视频和 MP4；SVG 视频提供导出 SVG 视频包、MP4 和 WebM。
- MP4 源视频直接导出原文件，保留画质与音频；其他源视频由宿主离线转码，SVG 帧在浏览器逐张渲染为 PNG 后交给宿主 FFmpeg 离线合成。按序号处理全部 SVG 帧，以原帧率生成固定间隔时间戳，不再依赖播放时钟或实时录制速度。30fps 的 300 帧输出为 10 秒；处理慢时延长导出耗时，不跳过中间帧。
- MP4 使用 H.264 / AAC、WebM 使用 VP9 / Opus。SVG 视频音频按原片段起点截取，短音频补静音至画面时长。导出采用媒体尺寸，奇数宽高补齐到偶数以适配编码器，不受画布节点缩放影响。
- 导出显示帧准备与编码进度，完成后分块下载为 `.mp4` 或 `.webm`；成功、失败或插件退出均清理临时帧与编码文件。同一画布一次导出一个视频，导出期间请保持应用运行。
- 导出缓存使用画布所在目录的 `.drawai-cache/video-exports/`，不依赖 Windows 系统临时目录的子进程写权限。开始导出前由 FFmpeg 实际试写输出路径并检查编码器，失败时立即显示目录及原因；底部状态支持选中文字复制，也可点击「复制提示」复制完整信息。
- 离线编码需要宿主可运行 FFmpeg：安装到 `PATH`，或启动 DSH 前设置 `DRAWAI_FFMPEG_PATH` 为 FFmpeg 可执行文件的绝对路径。本源码开发目录也识别 `_local/bin/ffmpeg.exe`（Windows）或 `_local/bin/ffmpeg`；发布包不包含该二进制。缺少 FFmpeg 时明确报错，不退回会掉帧的实时录制方式。源 MP4 直接导出及 SVG 视频包导出不依赖 FFmpeg。
- MP4 / WebM 编码默认使用白色底板，透明区域合成为白色；画面已有的背景色保持原样。直接导出源视频和 SVG 视频包保留原始内容。
- 加载、缺失和错误提示显示在节点内，可重试加载。
- 同一画布一次播放一个视频；切换播放对象时暂停旧视频并保留其进度。切换到其他画布或隐藏浏览器页面时暂停。

播放进度、循环、适配和预览状态均不写入 `.drawio`，也不进入撤销历史。视频封面在导入或复刻完成时生成。

播放器实现位于 `src/video-player.js`，由构建器内联至客户端 bundle。SVG 使用累计时间定位帧、最多四路并发加载帧；长序列按播放/跳转位置预取，最多保留 48 帧 SVG 内容，不等待全片加载。媒体事件和逐帧更新由播放器子组件订阅，不更新整张画布的 React 状态。节点删除、媒体类型切换、文件切换和卸载时清理加载状态、动画任务及 Blob URL。

验证：`node tools/check-video-player.mjs`，也已纳入 `npm test`。

播放默认开启声音，预览控制栏可静音。复刻结果保存原视频副本及片段起点，音频跟随播放、暂停、跳转和循环；SVG 视频包携带音频来源，WebM 导出混入对应片段音频。旧复刻包若没有保存音频来源，需重新复刻。
