# 右上角菜单整理方案

已清理冗长、重复的原生悬停提示，并实现图层列表（含缩略图和名称编辑）、导出参数面板、文件/编辑/视图分组、页面选择器和 100% 视图入口。以下保留整理设计说明；AI 回退的精确剩余步数尚未在客户端显示。

## 通用规则

- 保留「文件、编辑、图层、视图、导出」五个入口。
- 操作菜单点击展开；选区样式工具栏仍悬停展开。
- 菜单按用途分组并用分隔线区分，主要行只显示动作名称与快捷键。
- 删除重复说明；禁用原因、删除图层后的去向等必要信息在相关位置直接显示。
- 菜单高度受限，内容滚动；点击外部或 Esc 关闭，连续设置类操作保持面板打开。

## 文件

第一组：新建画布、打开。第二组：保存、另存为。

「选择目录」放进打开画布面板，不再占顶层菜单一项。保存项结合是否存在画布、是否有未保存修改启用；自动保存状态放在文件名附近，不在每项下重复解释。

## 编辑

按「撤销/重做」「剪切/复制/粘贴」「全选/查找」分组，快捷键右对齐。

「撤销 AI 改动」单独成组，显示真实剩余回退步数，避免与人工撤销混淆。把「整理几何（吸附到格线）」简化成「对齐到网格」，收进整理分组；不在标签中解释实现。

## 图层：改成列表面板

现在每层展开显示、锁定、设为当前、重命名、删除五个条目；N 层至少占 5N 行，选中元素时又追加 N 个移层条目。

改为一层一行：

| 显示 | 锁定 | 名称与元素数量 | 当前层 | 更多 |
| --- | --- | --- | --- | --- |
| 眼睛按钮 | 锁按钮 | 主流程 · 12 | 选中标记 | ⋯ |
| 眼睛按钮 | 锁按钮 | 注释 · 4 | — | ⋯ |

- 点击名称设为当前层；当前行高亮，隐藏层文字淡化，锁定状态直接可见。
- 眼睛、锁按钮只切换对应状态，不改变当前层，也不收起面板。
- 名称支持双击重命名；「⋯」收纳重命名、合并并删除图层。
- 删除沿用当前内容保留的语义，先显示「内容将并入 ××」，避免被误认为删除层内对象。最后一层禁用删除。
- 底部固定「＋ 新建图层」。有选区时额外显示「移动选中项（N）→ 图层选择器」，不为每层重复铺一条动作。
- 图层多于八层时显示搜索；列表限制高度，底部操作保持可见。

## 视图

第一组为视野：适应内容、100%。第二组为外观：网格开关、主题、偏好。

多页画布使用一个页面选择器显示「第 X / Y 页」，不把每一页当作独立菜单项。将「重新读取文件」移到文件菜单底部并改名为「重新载入」，与视觉外观区分。

## 导出：改成参数面板

现在六个条目实际是「全图/选区 × SVG/PNG/透明 PNG」的组合，格式、范围和背景混在操作名称里。

改成一个面板：

| 设置 | 控件 |
| --- | --- |
| 范围 | 整张画布 / 当前选区（N） |
| 格式 | PNG / SVG |
| 背景 | 保留背景 / 透明 |
| 分辨率 | 1× / 2× / 4×，仅 PNG 显示 |
| 文件名 | 以当前画布文件名预填，可编辑 |
| 结果信息 | PNG 显示预计像素尺寸；选区模式显示对象数量 |
| 提交 | 导出按钮 |

- 每次打开默认整张画布，范围选择明确可见；没有选区时禁用选区选项。
- 记住本机上次的格式、背景和分辨率，初始 PNG 使用当前已有的 4× 默认值。
- 选择 SVG 后隐藏分辨率，避免出现不适用的设置。
- 输出继续走现有浏览器下载流程；导出过程中显示状态，避免重复点击。
- 不显示尚未支持的 PDF 等格式；原生 drawio 文件副本归文件菜单的「另存为」，修正现有导出标题提及 drawio、菜单却没有该选项的不一致。

## 实施顺序

1. 图层列表面板，减少菜单膨胀。
2. 导出参数面板，合并重复入口。
3. 文件、编辑、视图分组及状态说明精简。

建议复用现有图层动作、导出请求和历史机制，仅重组界面入口，保持文件数据及撤销行为一致。
