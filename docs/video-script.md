## 0. 全片只围绕三条反常识点

功能巡礼（9 种形状、15 个 op、8 色调色板）**不要念**——那是商品页，不是视频。观众最后只需要记住三件事：

| # | 反常识点 | 必须拍到的画面 | 落在哪一镜 |
|---|---|---|---|
| 1 | **是真画布，不是图片** | 双击节点，字真的变了；拖动真的会动 | S02 / S06 |
| 2 | **鼠标就是上下文** | 框选两个节点说"这两个换成绿色"，真的变了 | S07 |
| 3 | **它不重画你的图** | 打开别人的脏稿子，改一处，`git diff` 只有那一处 | S11 / S12 |

第 3 条是全片的技术高光，也是同类工具做不到的地方。**先给结果、后还债**：S01–S10 只演"好用"，S11–S13 才讲"凭什么可信"。

## 1. 开拍前素材清单（缺一项就拍不出对应镜头）

| 素材 | 用途 | 怎么准备 |
|---|---|---|
| `demo/blank.drawio` | S05–S08 的干净空画布 | 画布面板「文件 → 新建画布…」 |
| `demo/login-flow.drawio` | S05 的产物，S09/S10 的输入 | 就是 S05 让模型画出来的那张，别手动造 |
| `demo/inherited-messy.drawio` | **S12 的核心素材** | 用 drawio 桌面版造：**≥3 页**、一页里有**分组容器**+**一张图片**+一个 HTML 标签的节点；第 1 页放几个普通节点供 AI 改 |
| git 仓库干净状态 | S11/S12 的 `git diff` | 录前 `git add -A && git commit -m wip`，确保 `git diff` 是空的 |
| drawio 桌面版 | S10 的 B-roll | 预开 `demo/login-flow.drawio`，窗口摆好 |
| 一张"糊掉的 AI 生成架构图" | S01 的痛点画面 | 任意一张 AI 生成的架构图**位图**，放大到 300% 备用 |

| `docs/social-preview.png` | 封面 | **README 顶部注释里预留着这个位置，目前还是空的**，顺手一起做 |

> ⚠️ **S12 是整支片子最容易被跳过、却最不能跳的准备项。** 没有多页+分组+图片的脏稿子，"无损保留"就只能靠嘴说——而嘴说的部分观众不信。

## 5. 录制与剪辑规范

- **分辨率 1920×1080，DSH 全屏**。右栏偏窄 → 需要特写时做 **1.5–2× 局部放大**，**绝不整屏缩放**（会糊，反而砸了"清晰"这个卖点）。
- **鼠标高亮 + 点击涟漪**必开；隐藏书签栏、通知、无关标签页、下载栏。
- **话和手错开**：先说"我现在框选这两个"，**停半秒**，再动手。观众的眼睛跟不上同时发生的两件事。
- **AI 思考间隔 2–4× 加速**，但保留 1 秒"在思考"的画面——全削掉会显得像造假。
- **字幕**：中文硬字幕；命令、路径、`selection` 这类关键词用等宽字体 + 高亮色。
- **音乐**：低频 lo-fi 铺底；S11/S12 的终端段把音乐降到 -18dB 以下，突显"技术感"。
- **每拍不超过 20–25 秒**；一个 beat 结束给一次轻微转场，别用花哨特效。

**删减顺序**（片长要压到 4:30 时，从下往上砍）：
1. S15（`render:true` 自查镜）
2. S04（三样东西快切压成 5 秒）
3. S13（乐观锁只留字幕，不演）
4. S08（并进 S07 的结尾一句话）
5. S06 压到 10 秒

**不可删**：S01、S02、S07、S10、S11、S12、S16。

## 6. 明确不要做

- ❌ 按功能表念参数（15 个 op、9 种形状、8 色调色板）——观众记不住，且像商品页
- ❌ 一上来讲 mxfile / 无损写回 / 原子写回——**先给结果，S11 再还债**
- ❌ 展示空白面板、首次加载的等待、画布从空到有的加载态
- ❌ 同时说话 + 操作
- ❌ 回避已知限制——S16 那 30 秒是加分项，不是减分项
- ❌ 用整屏缩放做特写
- ❌ 假装所有功能都完善（图层、大图性能、i18n 都还在早期，直说）
