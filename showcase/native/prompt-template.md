# 通用制作模板

页面开头那块「通用制作模板」的正文。`## 提示词全文` 以下是原样复制给 DrawAI 的内容；上方的说明只给维护者看，不会进入页面。

风格节里的提示词回答“这一支片子长什么样”，这份模板回答“这条片子怎么交”：填掉【本次内容】的七项，把整段发给 DrawAI，分镜、渲染、自检和交付报告都在流程里。

## 提示词全文

请使用 DrawAI 制作一支可播放的视频样片。你负责分镜、视觉设计、动画、声音、渲染和交付，并自行完成必要的检查与调整。

【本次内容】

- 风格：[填写 DrawAI 风格名称和 slug]
- 主题：[填写原创主题]
- 时长：[例如 10–12 秒]
- 画幅与帧率：[例如 1920×1080、30 fps]
- 画面内容与节奏：
  [填写该主题的关键情节和大致时间安排]
- 结尾文字：[填写文字；不需要则写“无”]
- 其他要求：[填写受众、品牌、素材等；没有则由你根据主题决定]

以上信息已经确定。其余没有指定的设计选择，请结合主题和风格自行决定并直接开始；只有缺少完成任务所必需的信息、且无法合理推断时才询问我。

【风格与原创性】

1. 先通过 mg_style 读取指定风格的施工包和必要源码，理解其配色、造型、动效节奏及引擎要求。如果素材包中已有该风格的参考帧，可以通过插件提供的素材查询方式读取；不要假定参考帧一定存在，也不要猜测素材路径。
2. 不要运行上游演示或从中截取参考帧，不要为了参考帧下载或补齐上游演示的专用素材。若素材包中没有可用参考帧，依据施工包和可用资料继续制作，并在交付时如实说明；不要声称看过实际未查看的参考帧。
3. 参考资料只用于理解风格，不照搬上游作品的故事、构图、角色、镜头顺序或品牌。围绕本次主题独立设计画面，并使用施工包要求的渲染引擎。
4. 优先使用 DrawAI 内置字体及可用素材；文字须准确、自然、清晰，不得缺字。使用外部素材时记录来源和许可。

【声音】

不需要旁白，除非上面的“其他要求”明确指定。

音乐和音效优先遵循本次内容中的声音要求；未指定时，根据主题、视觉风格和画面节奏选择合适的情绪、乐器与音色。

声音应服务于画面，控制音量与动态，避免意外失真、刺耳噪声和过密或过响的音效；需要紧张、低沉或强烈的声音时，也应与主题及叙事相符。

如果找不到合适且可用的声音，请先完成视觉样片，在交付时说明。仅凭素材名称或频谱不能证明主观听感：若没有实际试听，请明确写出“未实听”。

【自主制作与检查】

请实际调用 DrawAI 工具完成以下流程，不要只给我方案或代码：

1. 在当前工作区新建独立画布，添加视频节点和指定风格节点并连接；不要覆盖或修改已有作品。
2. 根据主题设计分镜和画面，建立视频工程。动作节奏应服务于本次内容，不要机械套用参考片的镜头时间。
3. 先制作定调画面，再预览覆盖开头、关键动作、高潮、转场和结尾的多个时间点。
4. 查看预览并自行修正明显问题，优先处理：
   - 画面无法看懂、主体不清楚、重要内容被遮挡；
   - 文字错误、缺字、过小或阅读时间不足；
   - 动作跳变、穿模、意外闪烁、黑帧或明显卡顿；
   - 风格引擎未按要求使用；
   - 声音过响、明显失真或与关键动作错位。
5. 每轮调整后重新检查受影响的位置。对同一个审美细节，原则上最多进行两轮有明确目标的调整；如果仍无法达到理想效果，保留当前最合适的版本，继续制作可审阅的样片，并在报告中说明差距。编译失败、黑帧、缺字等阻止正常播放或理解的问题应继续修复。
6. 渲染完整样片，等待渲染任务实际完成。在同一画布中创建独立样片视频节点并回填，让我可以播放；不要把静帧预览或尚在渲染的任务称为已完成。
7. 检查实际视频文件和画布节点，核对时长、分辨率、帧率、音频轨、黑帧、闪烁和文字。区分自动质检结果与实际观看或试听结果。

【交付报告】

完成后请简要报告：

- 画布路径、样片节点和可播放视频文件路径；
- 实际时长、分辨率、帧率，以及是否包含声音；
- 自行发现并修正过的主要问题；
- 自动质检未通过项、仍存在的视觉或声音问题；
- 是否实际观看了成片、是否实际试听了声音。

遇到无法解决的工具或渲染错误时，保留已有工程和文件，报告具体错误、已完成的部分及可继续的位置，不要伪称完成。
