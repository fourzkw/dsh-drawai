`image-trace-reference.png` 是用户提供的原图校准夹具。其三档输出已与用户的风格参考进行目视对照。

`check-image-trace.mjs` 使用默认画风、12 色、保留背景，锁定工作尺寸、棱角化容差、合并阈值和碎片数量，防止再次退化成大面积合并或像素细节直出。

`image-trace-small-reference.png` 是用户提供的 223×205 小尺寸角色图。旧工具栏将简化容差缩到约 0.503px，导致一万余条像素台阶线段；回归检查保证三档都保持工作像素中的 2px 折面简化，避免小图退化成像素画。不同分辨率可保留不同数量的小色块，不能为强求数量一致而保留像素噪点。
